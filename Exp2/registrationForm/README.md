# Activity 3: Commands to Create a React Native Application

### Create a New Project

```bash
npx @react-native-community/cli init MyApp
```

### Move into Project

```bash
cd MyApp
```

### Start Metro Bundler

```bash
npx react-native start
```

### Run Android Application

```bash
npx react-native run-android
```

# Activity 4: Purpose of Android Folder

The **android** folder contains all Android-specific files required to build and run the application.

### It includes

- Gradle files
- Android Manifest
- Native Java/Kotlin code
- Resources
- App configuration

---

# Activity 5: Why is the iOS Folder Present?

The **ios** folder contains all files needed to build and run the application on Apple devices.

### It contains

- Xcode project
- Swift/Objective-C files
- Info.plist
- Native iOS configuration

---

# Activity 6: Which File Represents the Main Screen?

The **App.js** file represents the main screen of a React Native application.

It is the first screen displayed when the application starts.

---

# Activity 7: Difference Between package.json and package-lock.json

| package.json                    | package-lock.json                               |
| ------------------------------- | ----------------------------------------------- |
| Stores project information.     | Stores exact versions of installed packages.    |
| Lists project dependencies.     | Locks dependency versions.                      |
| Can be edited manually.         | Automatically generated by npm.                 |
| Used while installing packages. | Ensures consistent installation across systems. |

---

# Activity 8: Purpose of node_modules Folder

The **node_modules** folder contains all installed libraries and dependencies required by the project.

### Examples

- React
- React Native
- Metro
- Babel
- Community packages

**Note:** This folder is automatically generated after running:

```bash
npm install
```

---

# Activity 9: Which File is the Entry File?

The entry file of a React Native application is:

```
index.js
```

It registers the root component (**App.js**) with the React Native runtime.

---

# Activity 10: What is Metro Bundler?

Metro Bundler is the JavaScript bundler used by React Native.

It combines all JavaScript files into a single bundle that can be executed by the mobile application.

### Uses

- Bundles JavaScript code
- Supports Fast Refresh
- Detects file changes automatically
- Improves development speed

---

# Activity 11: Command to Run Application on Android

```bash
npx react-native run-android
```

This command builds and installs the application on an Android emulator or connected physical device.

---

# Activity 12: How to Verify That a Physical Device is Connected?

Run the following command:

```bash
adb devices
```

If the device is connected successfully, its serial number will appear in the list.

Example

```
List of devices attached

R58N12345ABC    device
```

# Activity 13: Purpose of USB Debugging

USB Debugging allows an Android device to communicate with a computer using Android Debug Bridge (ADB).

### Uses

- Install applications
- Debug applications
- Run commands
- View logs
- Test applications directly on the device

---

# Activity 14: Testing on Emulator and Physical Device

### Emulator

- Android Studio Virtual Device
- No physical phone required
- Easy testing during development

### Physical Device

- Real hardware testing
- Better performance testing
- Tests camera, GPS, sensors, Bluetooth, etc.
